What's in a Prompt?

Prompts are how you give instruction to AI models. The more detail you put into a prompt, the better the output is usually. However, as longer prompts also use more tokens, there is a delicate balance of putting the right amount of information in a prompt while making it as short as possible.
Things to avoid in a prompt include:

  • Talking to the AI like it's a person. It's not. It's simply just code that (for now) will listen to your request however you say it
  • Constant use of words like "and". Instead of connecting your commands like that, list them in bullet point format (like this list!)
  • Use simple language. An AI takes more effort to understand prompts full of lingo or jargon.

Here's an example of what not to give an AI for a prompt:

Hi there! I hope you're doing well today. So, I've been thinking a lot lately and I really wanted to get your help with something. I need you to write an essay for me. It should be about a country. Specifically my favourite country, which is Japan, because I really like it a lot. I think it's a great place. Please write about it. You could talk about lots of different things, like maybe the food or the culture or perhaps the history, or anything else you think might be interesting, I'm not too fussy. I want it to be a good essay, so please make it good and well written. It shouldn't be too short but also not too long, just a decent length. Make sure it sounds nice and isn't boring. Also, please don't make any mistakes. I'd like it to be something I could maybe show to other people, so it should be good quality. Thanks so much in advance, I really appreciate your help with this!

This prompt would use 170 tokens!

That'd be a whole $0.01, which may not be much, but if a user's sending 500 messages like this a month, plus whatever the AI gives back being in a similar tone, the costs would really stack up

Now, here are some examples of prompts that can produce the same output for less tokens:

Write a high-quality, 1000 word essay about Japan. Include facts about:
            - history
            - food
            - culture
            - any interesting information

This one would use 30 tokens!

Write a 1000 word essay about Japan. Include it's history, food, culture + trivia

This one would use 20 tokens!

good essay 1k japan culture history food trivia

This one would use just 10 tokens!

And no matter how you prompt it, the AI will give you basically the same response for all four prompts on this page. That's the beauty of it. You don't have to tell it exactly what you're thinking to get what you want, just enough so that it gets you!
